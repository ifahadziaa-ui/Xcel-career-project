# Zen Kaku Gothic New (Latin subset)

Self-hosted through `next/font/local` in `src/app/layout.tsx`. Weights 300, 400, 500 and 700, one WOFF2 file each.

- **Family:** Zen Kaku Gothic New, version 1.002, by The Zen Kaku Gothic Project Authors (https://github.com/googlefonts/zen-kakugothic).
- **Licence:** SIL Open Font License 1.1 (`OFL.txt`, kept with the files as the licence requires). It permits bundling and redistribution; the font may not be sold on its own. No Reserved Font Name is declared.
- **Source:** the `latin` slice that Google Fonts serves for the family (fonts.gstatic.com, `/s/zenkakugothicnew/v19/`), downloaded 14 Nov 2026. These are byte-identical to the files `next/font/google` fetched earlier.
- **Coverage:** U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC, U+02C6, U+02DA, U+02DC, U+0304, U+0308, U+0329, U+2000-206F, U+20AC, U+2122, U+2191, U+2193, U+2212, U+2215, U+FEFF, U+FFFD. That includes the middle dot, en and em dashes, curly quotes, ellipsis, (R), (C), e-acute and the euro sign. It does **not** include Japanese, the arrows U+2190 and U+2192, U+25B6, or U+27A4. Text using those falls back to the system font. To add them, replace the files with the full font and subset deliberately.
